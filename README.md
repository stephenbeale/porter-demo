# Porter phone demo

Scan a vehicle service document with your phone; Claude reads the details and suggests personal data to black out. Then note what the mechanic told you but didn't write down ("the tyres will want doing by mid-November"): type or dictate it, Claude picks out the actions and dates, and you can export the reminders to your phone calendar (.ics). Bring your own Anthropic API key. It is stored only in your browser's localStorage and sent only to api.anthropic.com. Photos and advice notes go straight from your device to Anthropic. Dictation uses the browser's speech recognition, which in Chrome sends the audio to Google. A throwaway prototype; the real app keeps keys server-side. Generated from the private porter repo (web-demo/build.py).
